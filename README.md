A dog's one-line review of the mailman, written as a tiny Node program: `main.ts` validates the line (non-empty, a single line, within the character limit) and writes it to `entry.txt`. The mailman shows up every single day, knocks like he owns the place, and still sprints away from a 4kg security professional — five stars, would bark again.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
